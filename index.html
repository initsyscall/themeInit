Simple to Use

Define your theme once, use it everywhere.

theme.json 
// Define your theme configuration
{
  "name": "nightSyscall",
  "type": "dark",
  "colors": {
    "bg":  "#161423",
    "kwd":  "#A277FF",
    "fnc":  "#FF3366",
    "typ":  "#CBA6F7",
    "str":  "#F087BD",
    "num":  "#F6C177",
    "opr":  "#80FFEA"
  }
}
